# Training Services Analytics – Regional & Course Revenue

**GitHub Repository:** `Training-Services-Regional-Revenue-Analytics`

## Project Overview
Power BI dashboard analyzing training services revenue, orders, and customer trends across regions, courses, and months.

## Key Focus & Dashboard Features
* **Core KPIs:** Total Revenue, Total Orders, and Total Customers
* **Interactive Slicers:** Region and Year filters
* **Trend Analysis:** Regional and monthly revenue trends
* **Breakdown Matrix:** Course-by-region performance matrix
